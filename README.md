# onenote-mcp

Servidor [MCP](https://modelcontextprotocol.io) para leer, buscar y escribir en **OneNote de escritorio (Windows)** desde Claude Code u otro cliente MCP.

Se conecta a la app de OneNote instalada en tu PC mediante su interfaz COM: no necesita registrar una app en Azure ni iniciar sesión en otro servicio, y tus apuntes no salen de tu equipo salvo hacia el cliente MCP que los pide.
